# 🔐 Random Password Generator

A simple and responsive Random Password Generator built using React.js.  
This app generates strong and secure passwords instantly.

---

## 🚀 Features

- Generate random passwords
- Strong and secure password creation
- Copy password to clipboard 📋
- Responsive design
- Easy-to-use interface

---

## 🛠️ Technologies Used

- HTML
- JavaScript
- CSS
