A simple and secure Random Password Generator built using HTML, CSS, and JavaScript.
This app helps users generate strong passwords with customizable options.

Features:

1. Generate random passwords instantly

2. Include uppercase & lowercase letters

3. Include numbers and special characters

4. Adjustable password length

5. Copy password to clipboard

6. Responsive design

Technologies Used :

1. HTML – Structure of the app

2. CSS – Styling and layout

3. JavaScript – Password generation logic
